# Скриншоты проектов

Клади файлы сюда с точными именами — они уже прописаны в `src/data/projects.ts`.

| Файл | Проект | Что снимать |
|---|---|---|
| `gennis-v2.png` | Gennis V2 | Главный дашборд или страница профиля с данными |
| `turon.png` | Turon | Конструктор расписания (drag-and-drop) |
| `classroom.png` | Classroom | Облако слов или редактор формул |

- **Gennis Management** — `management-dashboard / voice / tasks / payroll.webp`

## Требования к скринам

- **Соотношение:** 16:10 (например 1600×1000). Карточка обрезает по верхнему краю, так что важное — сверху.
- **Формат:** PNG или WebP, до ~300 КБ. Пережать: `cwebp -q 82 shot.png -o shot.webp` (тогда поправь расширение в `projects.ts`).
- **Тёмная тема** приложения смотрится на сайте лучше — фон карточки тёмный.
- **Данные:** замажь или подмени реальные ФИО, телефоны, суммы и адреса. Это чужой продакшн.
- Снимай окно браузера **без** табов и адресной строки — только сам интерфейс.
- Без пометок маркером и выделений — они попадают на публичный сайт.

Пока файла нет, карточка показывает аккуратную заглушку с монограммой — сайт не ломается.

## Как подключать

Один проект может держать несколько скринов — они открываются в лайтбоксе.
Правится в `src/data/projects.ts`, поле `shots`:

```ts
shots: [
  { src: "/projects/turon.webp", caption: { en: "...", ru: "..." } },
],
```

Пока `shots` нет — карточка показывает заглушку с монограммой.

## Обезличивание

`scripts/redact-screenshots.py` пикселизует зоны с персональными данными
(имена, телефоны, суммы) и экспортирует WebP. Прописываешь прямоугольники
в `REDACTIONS` и запускаешь `python3 scripts/redact-screenshots.py`.
Пикселизация необратима — в отличие от блюра.

## Чьи это скрины

Обезличивание снимает риск для людей в данных. Оно не отвечает на второй вопрос —
имеешь ли ты право показывать чужой продукт. Это отдельное разрешение, и его надо
спрашивать у владельца проекта.

**Yoshlar Agentligi скринов здесь нет намеренно.** Государственная система по работе
с несовершеннолетними в трудной ситуации: даже без единого имени кадры раскрывают
структуру учёта, категории (пробация, наркотики), статистику по районам и рейтинг
силовых ведомств. Проект описан в портфолио текстом — этого достаточно.

**Лучший источник скринов — локальный запуск с сид-данными.** В `gennis-v2` для этого
есть `seed_local.py`, `seed_student.py`, `seed_jamoa2.py`. Кадр выглядит так же, но он
целиком твой: ни замазанных пятен, ни вопросов о разрешении.
